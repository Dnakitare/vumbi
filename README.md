# Vumbi

A daily browser rally game with its heart in the Safari Rally. One seeded stage per day, the same red-murram road for everyone: race it, beat your own ghost, paste your time at a friend.

**Play: [dnakitare.github.io/vumbi](https://dnakitare.github.io/vumbi/)**

This repository hosts the built game only; the source lives in a private repo. Car models are the paid [Retro Rally Pack by designersoup](https://designersoup.itch.io/retro-rally-pixel-art-asset-pack), used with purchase and credited in `models/CREDITS.txt` of the deployed site.
